Frequently asked questionsUnderstand what the QR code opens and how the shared link works.

What happens after someone scans the QR code?

WhatsApp opens a chat with the selected phone number. The message appears in the composer, ready for the customer to review and send.

What does Copy Link copy?

It copies this website address with the phone number and message encoded in the URL hash. Opening the link restores the setup and generates the QR code again.

Does the downloaded QR code open this website?

No. The QR code itself contains the direct WhatsApp chat address, so scanners go straight to WhatsApp.
